# history.ezhdanov.com

Истории о местах вокруг вас. Открываете на улице, разрешаете геолокацию, и приложение рассказывает, что здесь происходило: взрослым или детям 6-7 лет, голосом или текстом, на русском или английском.

- **Рядом со мной**: радиус поиска и длина рассказа в минутах. Claude предлагает темы по тому, что реально есть вокруг; выбираете темы (или ничего) и нажимаете «Сгенерировать истории».
- **Иду в…**: отмечаете точку на карте или находите её по названию. Приложение строит пеший маршрут и рассказывает, что будет слева и справа по пути.
- **Детям**: короткие истории простыми словами и вопрос после каждой, квиз с вариантами или открытый вопрос (ответ можно сказать голосом).
- **Разговор**: в любой момент можно перебить и спросить голосом или текстом, потом рассказ продолжится с того же места.

## Откуда берётся содержание

1. Места рядом: Википедия (местная, английская и язык интерфейса), мелкие объекты без статей из Викиданных, адрес точки из OpenStreetMap (Nominatim), маршрут из OSRM.
2. Для каждой истории берётся текст самой подробной статьи о месте, и Claude пишет историю по нему. Под историей есть ссылка на источник.
3. Claude работает через ваш API-ключ (Настройки). Ключ хранится только в браузере и уходит только в `api.anthropic.com`.

## Голос

Рассказ читает нейросетевой голос, если в настройках выбран сервис и вставлен его ключ:

- **ElevenLabs** (модель `eleven_v4`): самый выразительный, без суточных лимитов, дороже.
- **Google Gemini** (`gemini-3.8-flash-tts`): заметно дешевле, но у Google есть лимит запросов в сутки, поэтому текст уходит крупными отрывками.

Ключ хранится только в браузере и уходит только в свой сервис (`api.elevenlabs.io` или `generativelanguage.googleapis.com`). Звук играет обычный проигрыватель страницы, поэтому рассказ слышно в беззвучном режиме и с погашенным экраном, а пауза и «следующая» работают с экрана блокировки и из наушников.

Без ключа читает голос, встроенный в телефон (Web Speech API): бесплатно, но механически. Он же подхватывает рассказ с того же предложения, если сервис отказал (плохой ключ, лимит, нет связи). Распознавание речи для вопросов голосом встроенное.

## Геолокация

Место определяется в два приёма: быстрый замер по сети и точное наблюдение, из которых берётся лучшее. Если телефон место не отдаёт, приложение пишет причину (нет доступа, только примерная геопозиция, нет сигнала), показывает шаги именно для этого телефона и браузера и даёт указать место по названию или нажатием на карту. В подсказке есть сводка «Что ответил телефон», её можно скопировать для разбора.

## Устройство

Статический сайт без сборки (GitHub Pages): `index.html`, `css/`, `js/` (ES-модули).

| Файл | Что внутри |
|---|---|
| `js/app.js` | запуск, переключение экранов |
| `js/home.js` | главный экран: карта, настройки рассказа, темы |
| `js/session.js` | экран историй: план, рассказ, вопросы, разговор |
| `js/prompts.js` | все инструкции для Claude и схемы ответов |
| `js/ai.js` | запросы к Claude API (модели, настройки размышлений, ошибки) |
| `js/places.js` | поиск мест: Википедия, Викиданные, Nominatim |
| `js/route.js` | пеший маршрут и места вдоль него |
| `js/geo.js` | расстояния, азимуты, «слева или справа от пути» |
| `js/speech.js` | выбор голоса (нейросетевой или телефона), голос телефона, распознавание речи |
| `js/tts.js` | нейросетевой голос: запросы к ElevenLabs и Gemini, нарезка текста на отрывки, проигрывание |
| `js/location.js` | геолокация: замеры, причины отказа, повторные попытки |
| `js/geohelp.js`, `js/platform.js` | подсказка, как включить геолокацию на этом телефоне |
| `js/sheet.js` | выдвижное окно снизу (настройки, подсказки) |
| `js/mapview.js` | карта (Leaflet, плитки OpenStreetMap) |
| `js/settings.js` | окно настроек |
| `js/i18n.js` | тексты интерфейса на русском и английском |
| `vendor/claude.js` | Anthropic SDK для браузера, сборка из `tools/claude-bundle/` |
| `vendor/leaflet/`, `vendor/fonts/` | карта и шрифты (Sofia Sans Condensed, Literata) |

Модели: служебные задачи (темы, план, вопросы) делает Claude Haiku 5.5, истории по умолчанию пишет Claude Sonnet 5.5. В настройках можно выбрать «Быстро» (всё на Haiku) или «Максимум» (истории на Opus 5.5).

## Проверки

```bash
node tests/unit.mjs                        # геометрия, предложения, слияние мест, нарезка для голоса, геолокация
python3 tests/e2e.py                       # интерфейс в мобильном браузере с подставной сетью (нужен playwright и Chrome)
E2E_BROWSER=webkit python3 tests/e2e.py    # то же на движке Safari
```

Сервисы голоса и геолокация в проверках подставные (`tests/mocks.py`): настоящие ключи для них не нужны.

Пересобрать `vendor/claude.js`:

```bash
cd tools/claude-bundle && npm install && npm run build
```
